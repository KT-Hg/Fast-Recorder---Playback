🖥️ Window capture

Photographs a whole application window through the OS — a browser window with DevTools open, an editor, a terminal, a design tool. Everything the window shows on screen ends up in the image.

  1. Bring the window you want to capture on screen (not minimised).
  2. Press the button below — Chrome opens its window picker.
  3. Pick the window, then press Share.
  4. A countdown starts — switch to that window and set up what you want in the shot. The count shows in a small window floating above everything, and on the extension icon in the Chrome toolbar. Either one, or this window, can cancel it.
